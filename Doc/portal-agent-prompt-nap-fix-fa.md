## ۰. چرا این کار لازم است

پورتال امروز **آدرس غلط، مختصات غلط و لینک‌های شبکه اجتماعی غلط** نشان می‌دهد.

سه پیامد واقعی:

۱. **قانون NAP شکسته است.** موتورهای جستجو نام/آدرس/تلفن را در همه منابع مقایسه
   می‌کنند. ناسازگاری بین سایت رسمی و پروفایل گوگل، رتبه محلی را مستقیماً پایین
   می‌آورد. دیروز بازینو در OpenStreetMap و دو دایرکتوری KKTC با آدرس **جدید**
   ثبت شد — الان سایت خودمان تنها جایی است که آدرس قدیمی را می‌گوید.

۲. **لینک‌های شبکه اجتماعی به حساب‌های ناموجود می‌روند.** `instagram.com/bazino`
   حساب بازینو نیست؛ حساب واقعی `bazinopro` است. هر کلیک روی این لینک یک مشتری
   از دست رفته است.

۳. **مختصات نقشه حدود ۸۰ متر خطا دارد** و کاربر را به نقطه اشتباه می‌برد.

### 🔴 درباره تلگرام و یوتیوب — مهم

نام کانال تلگرام رسمی **هنوز توسط مالک تأیید نشده** و کانال یوتیوب **وجود ندارد**.

`t.me/bazino` و `youtube.com/bazino` مقادیر حدسی seed هستند. طبق قانون صداقت

نیست چون این فهرست از `siteSettings` قابل ویرایش است.

### ۱-ب. لینک‌های شبکه اجتماعی (خطوط ۱۴۰–۱۴۲)

سه ردیف فعلی با این جایگزین شوند:

```ts
{ id: '1', name: 'اینستاگرام کلوپ', platform: 'instagram', url: 'https://instagram.com/bazinopro' },
{ id: '2', name: 'فیسبوک کلوپ', platform: 'facebook', url: 'https://facebook.com/bazinopro' },
{ id: '3', name: 'واتساپ', platform: 'whatsapp', url: 'https://wa.me/905391333747' },
```

⚠️ اگر `platform` یک union type محدود است، مقادیر `facebook` و `whatsapp` را به
تعریف تایپ اضافه کن و مطمئن شو `getSocialIcon` برایشان آیکون دارد. اگر آیکون
مناسب موجود نیست، از آیکون عمومی لینک استفاده کن — **ولی رندر نباید بشکند.**

### ۱-ج. مقدار `club_map_url`

خط ۱۱۷ لینک کوتاه گوگل‌مپس دارد (`maps.app.goo.gl/rUohkLWxSmpBTjsKA`). این لینک
بررسی و **درست** است — به محل واقعی می‌رسد. **دست نزن.**

## ۵. بچ ۴ — دیتابیس زنده

🔴 **مهم‌ترین بخش. بدون این، سه بچ قبلی روی production اثری ندارند.**

`SAMPLE_SETTINGS` فقط وقتی اعمال می‌شود که جدول خالی باشد. دیتابیس فعلی از قبل
مقادیر غلط را دارد و seed دوباره اجرا نمی‌شود.

پس از دیپلوی، این مقادیر را در `settings` دیتابیس زنده به‌روزرسانی کن:

```sql
UPDATE settings SET value = 'İskele, Long Beach, Mackenzie Square, Vista Mare, Lobby, Unit No. 5' WHERE key = 'club_address';
UPDATE settings SET value = '35.2634752' WHERE key = 'club_map_lat';
UPDATE settings SET value = '33.9088575' WHERE key = 'club_map_lng';
```

و رکورد `social_links` را با سه لینک جدید بازنویسی کن.

**روش ترجیحی (§۲۷ API-First):** اگر پنل مدیریت این فیلدها را دارد — و دارد
(`AdminPanelTab.tsx:3996-4018`) — از همان مسیر انجام بده، نه SQL مستقیم.
