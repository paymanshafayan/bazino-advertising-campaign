## اسناد و منابع خارج از `Doc/`

- `../README.md` — نمای کلی استودیو و مسیرهای شروع.
- `../SKILL.md` — مأموریت و روش کار ایجنت.
- `../skills/README-fa.md` و `../skills/knowledge/README-fa.md` — نقشهٔ اسکیل‌ها و منابع دانش.
- `../skills/bazino-advertising-growth-agent/SKILL.md` — اسکیل اصلی بازینو و قواعد پروژه.
- `../marketing-app/README.md` — خلاصهٔ فنی برنامه؛ راهنمای کاربر انگلیسی به آن پیوند دارد.
- `../marketing-app/src/` و `../marketing-app/tests/` — مرجع نهایی رفتار پیاده‌شده و پوشش آزمون؛ کدهای نمونه/رندر mock شاهد اتصال زنده نیستند.
- `../../plans/` — پلن‌های رسمی شماره‌دار.
- `../Assets/` — مراجع تصویری برند و شخصیت‌ها؛ استفاده از شخصیت کودک کنار محتوای بزرگسالانه/خشونت‌آمیز ممنوع است.
- `../Daily/2026-10-02/` — بستهٔ روز، preview HTML، کاروسل، ویدئو و زیرنویس‌های همان روز.

برای همهٔ secrets، credentialها و دادهٔ خصوصی از فایل‌های محلی امن برنامه استفاده کنید؛ هیچ‌یک نباید به این اسناد یا Git افزوده شوند.
