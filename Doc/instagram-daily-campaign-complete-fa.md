# ۹. روند تولید روزانه

## مرحلهٔ ۱: انتخاب موضوع

موضوع از تقویم هفتگی انتخاب و با آخرین پست‌ها تطبیق داده شود. اگر موضوع تورنمنت یا Affiliate است، سند رسمی همان موضوع نیز بررسی شود.

## مرحلهٔ ۲: تعیین قالب

مشخص شود محتوا Reel، Post تک‌ویدیویی، Carousel یا Story است. برای Reel، مدت، قاب، موسیقی، دیالوگ و CTA مشخص شود.

## مرحلهٔ ۳: آماده‌سازی بریف

بریف باید شامل موضوع، مخاطب، Hook، حرکت مونا، متن روی تصویر، گفتار، زبان، کپشن، ترجمه، CTA و هشتگ‌ها باشد.

## مرحلهٔ ۴: تولید یا تدوین

از فایل مرجع دقیقاً همان منبع تأییدشده استفاده شود. در اصلاحات، صدا، قاب، زمان و Overlayهای تأییدشده بدون اجازه تغییر نکنند.

## مرحلهٔ ۵: Preview

پیش‌نمایش با ترکیب نهایی ساخته شود. برای متن فارسی یا عربی، شکل‌دهی حروف، جهت RTL و فونت به‌صورت بصری بررسی شود.

## مرحلهٔ ۶: تأیید و نهایی‌سازی

پس از تأیید، خروجی استاندارد تولید شود. نسخهٔ نهایی با نسخهٔ Preview تطبیق داده شود.

## مرحلهٔ ۷: آماده‌سازی انتشار

کپشن ترکی، ترجمهٔ فارسی داخلی، هشتگ‌ها، کاور، نوع رسانه و وضعیت صف انتشار ثبت شوند. انتشار فقط با دستور یا تأیید معتبر انجام شود.

## مرحلهٔ ۸: ثبت پس از انتشار

برای هر محتوای Affiliate که درخواست کامنت دارد، Media ID دقیق از پاسخ رسمی انتشار برداشته شود و بلافاصله طبق دستورالعمل ثبت Media ID به پورتال ارسال شود.

# ۱۰. چک‌لیست کنترل کیفیت Reel

### محتوایی

- آیا موضوع و دسته درست انتخاب شده است؟
- آیا Hook در دو ثانیهٔ اول قابل فهم است؟
- آیا اطلاعات رویداد، جایزه و شرایط فقط از منبع رسمی گرفته شده‌اند؟
- آیا CTA با هدف واقعی محتوا هماهنگ است؟

### بصری

- آیا چهره و هویت مونا ثابت است؟
- آیا حرکت‌ها طبیعی و بدون تغییر شکل دست، صورت یا بدن هستند؟
- آیا فضای خالی کافی برای متن وجود دارد؟
- آیا متن روی صورت مونا قرار نگرفته است؟
- آیا کاور با قالب ثابت پیج هماهنگ است؟

### فنی

- آیا ویدئو ۹:۱۶ و ترجیحاً ۱۰۸۰×۱۹۲۰ است؟
- آیا صدا، موسیقی و کدک درست هستند؟
- آیا فریم اول سیاه یا ناقص نیست؟
- آیا پایان و CTA به اندازهٔ کافی خوانا می‌ماند؟

### زبانی

- آیا ترکی استانبولی طبیعی و بدون غلط است؟
- آیا متن فارسی در صورت وجود RTL درست دارد؟
- آیا کلمهٔ کلیدی Affiliate با زبان محتوا منطبق است؟
- آیا ترجمه معنا را تغییر نداده است؟

### صدا و Lip-Sync

اگر مونا گفتار دارد، هماهنگی لب و صدا باید بررسی شود. اگر هماهنگی کامل از نظر فنی ممکن نباشد، خروجی باید با برچسب «تطبیق صوتی حداکثری» ارائه شود و به‌عنوان Lip-Sync دقیق معرفی نشود.

# ۱۱. چک‌لیست Affiliate پس از انتشار

۱. مشخص شود رسانه متعلق به کمپین Affiliate است و درخواست کامنت دارد.

۲. Media ID عددی دقیق از پاسخ رسمی Instagram یا Meta API برداشته شود.

۳. نوع رسانه مشخص شود: `post`، `reel` یا `story`.

۴. زمان انتشار به فرمت ISO 8601 ثبت شود.

۵. Endpoint رسمی پورتال با `Idempotency-Key` برابر `instagram:<media_id>` فراخوانی شود.

۶. توکن در خروجی، لاگ یا گزارش نمایش داده نشود.

۷. پاسخ پورتال بررسی شود. پاسخ تکراری idempotent به‌معنای ایجادنشدن رکورد جدید است.

۸. نتیجهٔ ثبت Media ID جدا از وضعیت انتشار گزارش شود.

۹. ثبت Media ID به‌تنهایی به‌معنای تأیید نهایی Affiliate یا پرداخت کمیسیون نیست.
