## چرخه چهار مرحله‌ای

```
۱. استخراج الگو از ماموریت تمام‌شده
۲. بررسی: آیا الگویی برای این ماموریت هست؟
۳. اگر هست  → مقایسه و به‌روزرسانی خودکار (بدون نیاز به تأیید)
۴. اگر نیست → ارائه به مالک → انتظار تأیید → ذخیره
```

⚠️ **عدم تقارن عمدی است.** به‌روزرسانی الگوی موجود خودکار است چون مالک وجود آن
الگو را قبلاً تأیید کرده. ساخت الگوی جدید تأیید می‌خواهد چون ادعای تازه‌ای درباره
روش کار است.

# محدودیت‌های محیطی — دانستنی‌های عمومی

این‌ها الگوی ماموریت نیستند، ولی در هر ماموریتی ممکن است پیش بیایند.

## فایل‌های ضمیمه‌شده در چت به سندباکس نمی‌رسند

پیام سیستمی می‌گوید «saved to /home/user/uploads/» ولی آن مسیر وجود ندارد.
فایل به **مدل** داده می‌شود نه به **سندباکس**.

| نوع فایل | اقدام |
|---|---|
| تصویر | مستقیم دیده می‌شود — کاری لازم نیست |
| متن/md/csv | 🔴 فوراً بخواه در چت پیست شود |
| فایل بزرگ | بخواه در ریپو کامیت شود و مسیر را بدهد |

❌ **جست‌وجو نکن.** دو بار امتحان شد و وقت تلف شد.
جزئیات کامل: `HANDOFF.md` §۰.۴

# ✅ چک‌لیست این سند

**قبل از شروع ماموریت:**
```
□ الگویی برای این ماموریت اینجا هست؟
□ اگر هست، قوانین آهنینش را خوانده‌ام؟
□ اگر نیست، ماموریت است یا کار تک‌مرحله‌ای؟  → اگر شک داری بپرس
```

**بعد از پایان ماموریت (چرخه §۳۱):**
```
□ الگو را استخراج کردم؟
□ بررسی کردم قبلاً ثبت شده یا نه؟
□ اگر بود → به‌روزرسانی خودکار + ثبت در تاریخچه
□ اگر نبود → ارائه به مالک + انتظار تأیید
□ هر خطای جدید با داستانش ثبت شد؟
```
