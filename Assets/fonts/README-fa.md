# 🔤 گروه فونت مصوب تولید محتوا (۲۰۲۶-۱۰-۰۳)

**دستور مالک:** «این فونت‌های ماشینی هیچ مخاطبی نداره.» از ۲۰۲۶-۱۰-۰۳ استفاده از فونت‌های
پیش‌فرض سیستم (Tahoma، Arial، Calibri، Segoe UI) در هیچ متن رندرشده‌ای مجاز نیست.
این پوشه گروه فونت‌های جذاب و آزاد (SIL OFL 1.1) را نگه می‌دارد.

> نسخهٔ ترکی/انگلیسی به کار می‌روند، نه برای انتشار فارسی.

## قواعد استفاده (خلاصهٔ بند ۷٫۲ راهنما)

۱. در هر طرح **حداکثر دو خانوادهٔ فونت**: یکی تیتر (Bebas/Anton/Russo/Archivo/Oswald) و
   یکی متن (Poppins/Montserrat).
۲. اندازهٔ تیتر دست‌کم **۱٫۵ برابر** متن؛ کوچک‌ترین متن ۴۰ پیکسل در قاب ۱۰۸۰.
۳. همهٔ متن‌ها داخل **منطقهٔ امن ۹۰۰×۱۴۰۰** مرکز قاب ۱۰۸۰×۱۹۲۰ (یا ۱۰۸۰×۱۳۵۱ برای کاروسل).
۴. حداقل کنتراست ۴٫۵:۱؛ روی پس‌زمینهٔ شلوغ از جعبهٔ نیمه‌شفاف یا حاشیهٔ متن استفاده شود.

## مجوز

همهٔ فونت‌ها تحت **SIL Open Font License 1.1** هستند. متن مجوز هر فونت در فایل
`LICENSE-<font>-OFL.txt` همین پوشه است و باید همراه فایل فونت توزیع شود.
نام‌های محفوظ (Reserved Font Names) محترم است؛ فایل‌ها تغییر نام یا بازتوزیع تجاری
جداگانه نشده‌اند.

## وضعیت فنی روی رایانهٔ مالک

- مسیر تولید تصویر روی ویندوز: این فونت‌ها با `FontFamily` مبتنی بر فایل
  (`file:///…/BebasNeue-Regular.ttf#Bebas Neue`) بارگذاری می‌شوند تا به نصب سیستمی
  نیازی نباشد.
- ایموجی با فونت رنگی ویندوز (`Segoe UI Emoji`) رندر می‌شود؛ اگر موتور رندر ایموجی
  رنگی را پشتیبانی نکرد، ایموجی به‌صورت تصویر PNG کنار متن ترکیب می‌شود.
