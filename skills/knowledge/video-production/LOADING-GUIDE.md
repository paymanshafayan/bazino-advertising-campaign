# 🗺️ راهنمای دسترسی — اسکیل تولید ویدئو

**قاعده:** یک بخش بارگذاری → استفاده → **رها کن** → بخش بعد.

هرگز هر چهار بخش را همزمان بارگذاری نکن. کل اسکیل ۸۱۵ خط است؛ هر بخش
۱۰۰ تا ۳۱۱ خط. بارگذاری همه یعنی سه برابر بودجه لازم.

# چک‌لیست خود این راهنما

```
□ می‌دانم کدام بخش را لازم دارم؟
□ آیا جوابم در جدول «پرتکرار» بالا هست؟  → پس بارگذاری نکن
□ بخش قبلی را رها کرده‌ام؟
□ فقط یک بخش در حافظه دارم؟
```
