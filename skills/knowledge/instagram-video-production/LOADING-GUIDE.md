# 🗺️ راهنمای دسترسی — اسکیل تدوین ویدئوی اینستاگرام

**قاعده:** یک بخش بارگذاری → استفاده → **رها کن** → بخش بعد.
هرگز همهٔ بخش‌ها را همزمان بارگذاری نکن؛ هر ماموریت ۲ تا ۳ بخش لازم دارد.

---

## کدام مسیر برای کدام کار

| ماموریت | بخش‌ها | یادداشت |
|---|---|---|
| تدوین ریلز تازه از فوتیج موجود | `05` → `02` → `03` → `06` | مسیر پیش‌فرض |
| تبدیل ویدئوی فارسی به ترکی (بند ۳٫۵ب و ۷٫۶) | `03` → `04` → `06` | ماسک متن فارسی + زیرنویس ترکی |
| ویدئوی خبری (Merlin'in Kazanı) | `07` → `02` → `06` | ادعای عددی بدون منبع دوم ممنوع |
| ویدئوی فان/سرگرمی | `02` → `03` → `06` | ایموجی و ریتم تند |
| اصلاح ویدئویی که مالک رد کرده | `06` → `05` → `02` → `03` | بازسازی کامل، نه همان فایل |
| بررسی ویدئوی تحویلی (بازبینی) | `06` | فقط چک‌لیست |
| ساخت کاور/تصویر تمام‌قاب | `03` | فونت و منطقهٔ امن |

## هشدارها

- **`sections/03` و `sections/05` را همزمان باز نکن** مگر ویدئوی خبری پیچیده باشد.
- بخش‌های `references/` **فقط با نیاز مشخص** باز می‌شوند، نه به‌عنوان مطالعهٔ عمومی.
- قواعد بازینو (بخش ۲ `SKILL-fa.md` و `SKILL.md`) **همیشه** حاکم است، حتی اگر یک بخش
  چیز دیگری بگوید.
- این اسکیل اجازهٔ انتشار، هزینه یا تولید ویدئوی تازه نمی‌دهد.
