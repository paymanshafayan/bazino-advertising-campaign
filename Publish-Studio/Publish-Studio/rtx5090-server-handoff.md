### ب) دو ارتقای مصوب بعدی برای افزودن به موتور و API فعلی:

#### ۱. یکپارچه‌سازی `Openjutsu` (جایگزینی کاراکتر) در API فعلی (عدم نیاز کامل به `comfy-mcp`)
* **هدف:** افزودن قابلیت جایگزینی کاراکتر (`Character Swap`) با موتور `/root/Openjutsu` و اسکریپت `/root/Openjutsu-scripts/run-swap.py` مستقیماً به داخل `api_server.py` و `rtx5090_api_client.py` (که نیاز به نصب `Comfy-Org/comfy-mcp` را به طور کامل منتفی می‌کند).
* **مزایای معماری یکپارچه:**
  - استفاده از **قفل مشترک کارت گرافیک (`gpu_lock`)** بین `FreeVideo` و `Openjutsu` جهت جلوگیری ۱۰۰٪ از تداخل دو موتور و خطای پر شدن ۳۲ گیگابایت `VRAM`.
  - استفاده از همان بستر امن **`HTTPS` پورت `443`**، آپلود تکه‌ای مقاوم در برابر محدودیت شبکه، دانلود استریمی با تایید **`SHA-256`**، اعلان **وب‌هوک (`video.completed` / `video.downloaded`)** و پاکسازی خودکار ۱۰ ساعته.
* **گام‌های پیاده‌سازی:**
  1. بررسی آرگومان‌های ورودی/خروجی `/root/Openjutsu-scripts/run-swap.py` روی سرور.
  2. افزودن اندپوینت `POST /swap` (و مسیر تکه‌ای `/jobs/{job_id}/start-swap`) به `api_server.py` برای دریافت **ویدیوی مرجع + تصویر(های) کاراکتر** و تحویل مستقیم فایل `.mp4` خروجی.
  3. افزودن سوییچ `--swap` به کلاینت ویندوز `rtx5090_api_client.py`.

#### ۲. افزودن `Realism-LoRA` (`~75 MB`) به موتور `FreeVideo` و API فعلی
* **هدف:** ارتقای طبیعی بودن بافت پوست، جزئیات چهره و نورپردازی واقعی در خروجی‌های `MiniMax H3 Ref2VA`.
* **جزئیات فنی و گام‌های پیاده‌سازی:**
  1. دانلود فایل وزن‌های **`Realism-LoRA` (`~75 MB`)** و قرار دادن آن در مسیر مدل‌های سرور (مثلاً `/root/FreeVideo/models/loras/realism_lora.safetensors`).
  2. اضافه کردن پارامتر `use_realism_lora: bool = Form(True)` و `lora_strength: float = Form(0.8)` به اندپوینت‌های `/generate` و `/jobs/{job_id}/start` در `api_server.py`.
  3. تزریق خودکار LoRA در آرایهٔ `"loras"` داخل فایل `media.json` هنگام ساخت کار روی سرور و افزودن پرچم کنترل آن در `rtx5090_api_client.py`.
