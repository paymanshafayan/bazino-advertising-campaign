# مونا — اینفلوئنسر مجازی بازینو

مونا شخصیت تصویری رسمی کمپین‌های بازینو است.

| فایل | چه چیزی است |
|---|---|
| `mona-character-fa.txt` | شناسنامهٔ کامل شخصیت به فارسی |
| `mona-character-en.txt` | همان شناسنامه به انگلیسی |
| `../Assets/mona/` | ۵ تصویر مرجع مونا (پرترهٔ آواتار، ست برند، لباس روزمره، ست ورزشی، کلوزآپ نیازمند اصلاح) |

قواعد کامل شخصیت‌ها (مونا، هستی، یونا، لیا) در
[`../Doc/campaign/brand-characters-fa.md`](../Doc/campaign/brand-characters-fa.md) است.

## قواعدی که هرگز شکسته نمی‌شود

1. **چهره باید ثابت بماند:** موهای بلند قهوه‌ای تیره با هایلایت گرم، چشم قهوه‌ای، پوست
   زیتونی روشن مدیترانه‌ای، نیم‌لبخند. لباس و محیط عوض می‌شوند، صورت نه.
2. **هر تصویر تازه پیش از انتشار بازبینی بصری شود.** بدون دیدن تصویر، محتوا تأیید نیست.
3. **مونا تبلیغ متحرک نیست:** برند باید طبیعی داخل دنیای او باشد، مثل پیشنهاد یک دوست.
4. **هیچ محتوای ۱۶+ یا ۱۸+ کنار مونا نمی‌آید.**
5. **جذابیت او از شخصیت و حالات چهره می‌آید، نه از لباس تحریک‌آمیز.**
6. **عدد ساختگی نمی‌سازد:** مونا جایزه، تخفیف، قیمت یا شرایط تأییدنشده اعلام نمی‌کند.
7. **مونا از کتابخانهٔ ابزار تصویرسازی استفاده می‌شود، نه از فایل آپلودیِ هر بار.**

## برای ساخت تصویر تازه

شناسنامهٔ فارسی (`mona-character-fa.txt`) را به‌عنوان دستورالعمل ثابت بده و فقط بخش
«صحنه، لباس، حالت چهره و کار» را برای هر پست عوض کن. تصویر مرجع
`../Assets/mona/mona-portrait-avatar-01.png` را حتماً به مدل بده. خروجی را کنار پرترهٔ
مرجع بگذار و چهره را مقایسه کن؛ اگر تفاوت پیدا کرد، همان را نپذیر.
