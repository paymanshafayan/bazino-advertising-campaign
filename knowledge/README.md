## قواعد بارگذاری

1. برای هر درخواست فقط منبع مرتبط را باز کن؛ اگر دانشی کم است از شواهد معتبر بیرونی، مستند رسمی محصول و کد جاری کمک بگیر. ادعای «اسکیل موجود» دربارهٔ موضوعی که در این نمایه نیست نکن.
2. تاریخ، نام ابزار/مدل، مجوز بازاستفاده، اعتبار ادعا و تضاد منابع را ثبت کن. عدد فنی قدیمی را بدون تاریخ و آزمایش به دستور امروز تبدیل نکن؛ برای تعارض با سیاست مالک، توقف و سؤال.
3. دارایی‌های قدیمی ممکن است حق نشر، وضعیت تأیید یا حجم متفاوت داشته باشند. این انتقال **فایل رسانه‌ای را تکثیر نکرده**؛ ارجاعِ pinned به منبع، حق انتشار همان دارایی در کانال امروز نیست.
4. فناوری اتصال مرورگر/حسابِ پروژهٔ قدیمی «دانش بازاریابی قابل انتقال» نیست؛ به‌ویژه ذخیرهٔ رمز در مخزن مردود است. درگاه، API و مجوز زنده باید مستقل و با حداقل دسترسی طراحی/تأیید شوند.
