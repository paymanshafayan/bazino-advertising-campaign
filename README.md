# bazino-advertising-campaign

## آوانگار — تبدیل گفتار به متن برای ویندوز

برنامهٔ مستقل دسکتاپ در پوشهٔ [`avanegar`](avanegar) اضافه شده است؛ اسناد کمپین تغییری نکرده‌اند.

- میان‌بر سراسری برای شروع و پایان ضبط و درج در پنجرهٔ مقصد
- پردازش محلی Whisper، فارسی پیش‌فرض و رابط راست‌به‌چپ
- راه‌اندازی ویندوز: `avanegar/run-windows.bat` (نیازمند Python 3.11 x64)
- ساخت برنامهٔ مستقل: `avanegar/build-windows.bat`
