> **قانون مالک برای تغییر کد:** تغییر کد، تنظیم ساخت یا workflow فقط پس از ثبت پلن و تأیید صریح مجاز است؛ واژهٔ تأیید ثبت‌شده «شروع کن» است. این قاعده مجوز انتشار عمومی، DM یا هزینه‌کرد نیست.

# ژینوس بازینو

محیط کاری ایجنت متخصص بازاریابی بازینو برای پژوهش، طراحی کمپین، آماده‌سازی و بازبینی محتوا و سنجش نتیجه. اسناد و فایل‌های آماده به‌تنهایی به معنی اتصال زنده، انتشار واقعی یا تأیید مالک نیستند.

## وضعیت محصول جاری — ۲ اکتبر ۲۰۲۶

برنامهٔ جاری، محصول بومی Windows در [`marketing-app/`](marketing-app/README.md) با نسخهٔ **0.8.1** است؛ release خصوصی تأییدشده [`marketing-app-dev-41`](https://github.com/paymanshafayan/bazino-gamenet-portal/releases/tag/marketing-app-dev-41) و نصب آن روی رایانهٔ مالک ثبت شده است. راهنمای جامع انگلیسی برای کار با برنامه: [`Doc/BAZINO_MARKETING_STUDIO_WINDOWS_USER_GUIDE_EN.md`](Doc/BAZINO_MARKETING_STUDIO_WINDOWS_USER_GUIDE_EN.md).

- برنامه شش بخش دارد: اتصال، تنظیمات، مرورگر، رسانه، محتوای آمادهٔ انتشار و لاگ.
- Affiliate فقط Reel در Instagram است. پس از انتشار موفق همان Reelِ جداگانه تأییدشده، `media_id` واقعی به endpoint **موجود** پورتال فرستاده می‌شود؛ مسیر یک‌طرفه است و webhook/callback تازه ساخته نمی‌شود.
- کارت Portal Ingest دکمهٔ آزمون اتصال ندارد. endpoint ثبت‌رسانه POST است؛ از آن برای تست استفاده نکنید. GET فقط‌خواندنی در صورت نیاز، کار آینده و نیازمند پیاده‌سازی است.
- انتشار عمومی و DM واقعی به تأیید جداگانهٔ مالک برای همان محتوا/عملیات نیاز دارند. وجود پست در صف یا سالم‌بودن اتصال، اجازهٔ انتشار نیست.
- صندوق فرمان GitHub در زمان گوش‌دادن فرمان‌های تأییدشدهٔ ایجنت را **بدون پنجرهٔ تأیید** اجرا می‌کند. برای قطع دسترسی از «Stop listening» یا بستن برنامه استفاده کنید.

## قاعدهٔ شواهد

کد پیاده‌شده، آزمون واحد، mock، build موفق، تست اتصال، گزارش زنده و انتشار واقعی شواهد متفاوت‌اند. هیچ‌کدام را با دیگری یکی نگیرید. برای هر ادعای عملیاتی، زمان و شاهد دقیق را در `HANDOFF.md` ثبت کنید. رسانه و secrets یا داده‌های خصوصی/موقت را بی‌بررسی stage نکنید؛ `git add -A` ممنوع است.
