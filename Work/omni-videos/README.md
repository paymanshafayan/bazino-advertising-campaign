# کارهای تصویری و ویدئویی — مرجع‌ها

این پوشه تصاویر مرجعِ استودیو را نگه می‌دارد: تصاویری که چیدمان، سبک یا ساختار یک کار
را تعیین می‌کنند و هنگام ساخت محتوای تازه باید کنارشان نگاه شوند.

**این دو شخصیت با مونا فرق دارند.** مونا اینفلوئنسر برند بازینو است (پوشهٔ `../Mona/`)؛
الارا و کائلن شخصیت‌های یک مجموعهٔ تصویری-بازی‌محورند که در این پوشه به‌عنوان مرجع
سبک و ثبات چهره نگه داشته شده‌اند. اگر کمپینی با آن‌ها اجرا می‌شود، اول با مالک مشخص شود
که این دو کی هستند و برای چه کاری استفاده می‌شوند.

## پیشنهاد ترتیب کار برای ویدئو

1. از عکس واقعی سالن (`../Images/club/`) شروع کنید؛ نور و فضای واقعی، اعتماد می‌آورد.
2. چیدمان و سبک را از تصویر مرجع بگیرید، نه از حافظه.
3. متن روی ویدئو کوتاه و خوانا باشد؛ قیمت و جایزه نیاید.
4. پیش از انتشار، خود ویدئو را یک بار کامل ببینید.
