# ژینوس برای Windows

این پوشه سورس برنامهٔ بومی Windows است. راهنمای کامل کاربر **به انگلیسی** در [`../Doc/BAZINO_MARKETING_STUDIO_WINDOWS_USER_GUIDE_EN.md`](../Doc/BAZINO_MARKETING_STUDIO_WINDOWS_USER_GUIDE_EN.md) است. قرارداد صف نشر و مرزهای Zernio/پورتال در [`PUBLISHING.md`](PUBLISHING.md) آمده‌اند.

## وضعیت فعلی

- نسخهٔ کد: **0.8.2** (ساختِ در جریان برای نصب روی رایانهٔ مالک؛ نسخهٔ نصب‌شدهٔ فعلی همچنان 0.8.1 است)، هدف Windows x64 و .NET 10 self-contained.
- **تغییرات 0.8.2 نسبت به 0.8.1 (طبق تأیید مالک، ۲۰۲۶-۱۰-۰۳):** بخش تازهٔ «گزارش روزانه» با نمودار (بازدید روزانه/روند دنبال‌کننده/ترکیب تعامل/جدول بهترین پست‌ها و کاشی‌های عددی انیمیشنی، فقط‌خواندنی)،
  اصلاح ثبت Task ویندوز (عنصر نامعتبر `AllowStartIfOnBatteries` جای خود را به `DisallowStartIfOnBatteries` در ترتیب معتبر طرح‌واره داد + دو مسیر جایگزین ثبت)،
  بررسی خودکار در هر اجرای برنامه بعد از ساعت ۰۸:۰۰ با فایل نشانهٔ `%LOCALAPPDATA%\BazinoMarketing\daily-report.marker.json` (اگر امروز ثبت نشده باشد، گزارش ساخته و روی همان برنچ ثبت می‌شود)،
  شروع تمام‌صفحه (بیشینه؛ کلید `F11` برای تمام‌صفحهٔ بدون‌حاشیه)، و بازطراحی کامل رابط با طرح روشن، نوار کناری و نشان/رنگ برند هر ابزار. نام انگلیسی محصول در اسناد **Jinus** است. هیچ وابستگی NuGet تازه‌ای اضافه نشده است.
- انتشار خصوصی تأییدشده: [`marketing-app-dev-41`](https://github.com/paymanshafayan/bazino-gamenet-portal/releases/tag/marketing-app-dev-41). برنامه روی رایانهٔ مالک نصب شد؛ شواهد و حدود آزمون زنده در [`../HANDOFF.md`](../HANDOFF.md) ثبت شده‌اند.
- CI اجرا `37005912991` سبز شد: ۱۵۱ آزمون Core، کامپایل متقاطع WPF، آزمون‌های Windows/DPAPI و انتشار self-contained؛ رندر هر ۶ صفحه نیز موفق بود. این آزمون‌ها به‌تنهایی سلامت سرویس‌های زنده، اجرای Task یا مجوز انتشار را اثبات نمی‌کنند.
- مسیر UI در 0.8.2: `اتصال`، `گزارش روزانه`، `محتوای آماده انتشار`، `رسانه و ویدئو`، `مرورگر`، `تنظیمات` و `لاگ رویدادها` (نوار کناری).
- Affiliate فقط Reel است؛ پس از انتشار موفقِ Reel تأییدشده، گزارش یک‌طرفه به endpoint موجود Portal می‌رود. هیچ webhook/callback تازه‌ای ساخته نمی‌شود.
- صفحهٔ تنظیم Portal در نسخهٔ بررسی‌شده دکمهٔ آزمون اتصال ندارد. از endpoint ثبت‌رسانه برای آزمون استفاده نکنید.

## معماری و مسیرها

```text
marketing-app/
├── src/BazinoMarketing.Core/       # تنظیمات، DPAPI، صندوق GitHub، فرمان‌ها، مرورگر، رسانه، نشر و Insights
├── src/BazinoMarketing.App/        # WPF، ViewModels، صفحات و Task ویندوز
├── tests/BazinoMarketing.Core.Tests/ # آزمون‌های هسته و اتصال بین‌زبان‌ها
├── agent/mailbox.cjs               # ابزار Node سمت عامل برای صندوق فرمان
├── ci/marketing-app-ci.yml         # الگوی workflow؛ workflow زنده در .github/workflows/
└── scripts/publish.ps1             # اسکریپت انتشار محلی برای مالک
```

تنظیمات محلی در `%LOCALAPPDATA%\BazinoMarketing\settings.json` ذخیره می‌شود؛ اسرار جداگانه با Windows DPAPI رمزگذاری می‌شوند و نباید وارد Git شوند. گزارش‌ها در `logs/` هستند. پوشهٔ پیش‌فرض رسانه `%USERPROFILE%\Downloads\BazinoMarketing\` است.

## شروع سریع برای اپراتور

1. فایل `BazinoMarketing.exe` را از release خصوصی تأییدشده دریافت و اجرا کنید؛ نسخهٔ 0.8.1 از قبل نصب شده است و نیازی به تکرار به‌روزرسانی نیست.
2. در **Settings** کارت GitHub و Zernio را بررسی کنید، اسرار را فقط در فیلدهای امن وارد کنید و هر کارت را جداگانه ذخیره و آزمایش کنید.
3. کارت Portal فقط URL پایه و توکن ingest را ذخیره می‌کند؛ **آزمون اتصال ندارد**. توکن Portal با کلید Zernio فرق دارد. هرگز POST آزمایشی به endpoint موجود نفرستید.
4. در **Connection** وضعیت‌ها را تازه کنید. صندوق فرمان هنگام فعال‌بودن GitHub به‌طور خودکار گوش می‌دهد و فرمان‌های عامل را بدون پنجرهٔ تأیید اجرا می‌کند؛ در زمان عدم نیاز، «Stop listening» را بزنید یا برنامه را ببندید.
5. برای فایل‌ها از **Media** و برای مرور صفحه از **Browser** استفاده کنید. دانلود اینستاگرام فقط یک URL مشخص را می‌گیرد؛ فهرست Savedها/دانلود انبوه موجود نیست.
6. در **Ready-to-publish** محتوا را دقیق بازبینی کنید. تأیید کارت، انتشار زمان‌بندی‌شده را مجاز می‌کند؛ زمان‌بند فقط وقتی برنامه باز است کار می‌کند. انتشار عمومی و DM واقعی نیازمند تأیید جداگانهٔ همان محتوا/عملیات‌اند.
7. خطاها و شواهد را از **Logs** و گزارش عیب‌یابی پالایش‌شده بررسی کنید.

## نکتهٔ امنیتی حیاتی

فرمان‌های پذیرفته‌شده از صندوق GitHub بی‌پرسش اجرا می‌شوند. برچسب‌های خطر و تیک‌های مجوز ابزار در تنظیمات، گیت اجرایی برای این جریان نیستند. اتصال را فقط هنگام نیاز باز نگه دارید. محتوای رسانه‌ای آپلودشده به GitHub وارد مخزن خصوصی و تاریخچهٔ Git می‌شود؛ فایل حساس را نفرستید.

## توسعه و آزمون

سورس راه‌حل در `BazinoMarketing.slnx` است. نسخهٔ .NET از `global.json` و مقدار `Version` از `Directory.Build.props` خوانده می‌شود. برای مسیر تأییدشدهٔ build/test، workflow زندهٔ [`.github/workflows/marketing-app-ci.yml`](../../.github/workflows/marketing-app-ci.yml) را ببینید؛ فایل `ci/marketing-app-ci.yml` فقط الگوی داخل پوشه است. اجرای مرحلهٔ انتشار ویندوزی یک private pre-release می‌سازد و باید مطابق پلن/تأیید مالک انجام شود.
