# قالب‌های تحویل استودیو

**منشأ:** اقتباس از [Doc/output-templates-fa.md پروژهٔ قدیمی](https://github.com/paymanshafayan/bazino-advertising-campaign/blob/f84461608163c1d2478501eecd9919b4488d50a0/Doc/output-templates-fa.md) و [DAILY_FEEDBACK_SYSTEM.md](https://github.com/paymanshafayan/bazino-advertising-campaign/blob/f84461608163c1d2478501eecd9919b4488d50a0/DAILY_FEEDBACK_SYSTEM.md). قواعد مقدم در [HANDOFF.md](../HANDOFF.md) هستند. نمونه‌ها برای **تحویل/بررسی**‌اند؛ پرکردن قالب، اجازهٔ ارسال یا انتشار نمی‌دهد. مقدارهای نمونه/گفتار تاریخی را پیش از استفاده با مالک و پورتال تطبیق بده.

## ۱. کارت تصمیم برای یک محتوای پیشنهادی

```text
عنوان/شناسه: ...                 وضعیت: پیشنهاد / پیش‌نویس / بازبینی / تأییدشده
هدف و کمپین: ...                 مخاطب: ...
کانال/حساب/زبان: ...             قالب: ...
هوک ۰–۳ ثانیه: ...               پیام واحد: ...
سناریو و شات‌های کلیدی: ...      نقش/مرجع شخصیت: ...
CTA: ...                         موسیقی/ریتم/صدا: ...
کپشن/متن تصویر/هشتگ: ...        دارایی لازم: ...
ادعای واقعی و منبع/تاریخ: ...    موارد نامعلوم یا نیازمند تأیید: ...
انتظار آزمون و KPI: ...          گیت بازبینی/تأیید مالک: ...
```

برای Reel عدد/ساعت/قیمت/جایزه/ظرفیت/شرایط داخل رسانه قرار نده؛ لینک فقط بر اساس سیاست همان کمپین. الگوی قدیمیِ ۱۰ جزء برای سه Reel صرفاً قالب قابل اقتباس است، نه تعهد روزانه.

## ۲. یک پرامپت ویدئو در هر نوبت — نسخهٔ مرحله‌ای

````markdown
# پرامپت N از M — [هدف صحنه]

**وضعیت:** پیش‌نویس، هنوز تأیید/ذخیره/منتشر نشده است
**ابزار و نسخهٔ بررسی‌شده:** [نام + تاریخ، نه حدسی]

```text
[یک بلوک قابل کپی:
 نسبت/مدتِ معتبر همان ابزار؛ سالن؛ شخصیت و روش مرجع؛ محتوای صفحه؛
 کنش + قاب + دلیل حرکت دوربین + نقاط برش + فریم پایانی؛
 گفتار/صدا/lip-sync مطابق متن نهایی؛ متن روی تصویر در safe-zone؛
 منع ادعا، محتوای سنّی، ممنوعیت‌های Reel؛ اگر دو نسخهٔ TR/FA
 لازم است، هر دو با موقعیت/زمان‌بندی و پشتیبانی RTL در همین بلوک]
```

### ترجمهٔ کامل فارسیِ بلوک بالا
[ترجمهٔ **تمام** دستورها، صدا، نور، حرکت و متن، نه فقط زیرنویس]

**فایل/مرجع انتخابی:** [مسیر/مالکیت/وضعیت تأیید؛ Flow و سایر مدل‌ها تفاوت دارند]
**آنچه تست نشده:** ...
**تصمیم مالک:** این نسخه و مرجع را تأیید می‌کنید تا بعداً ذخیره/مرحلهٔ N+1 آماده شود؟
````

اگر مالک متن اولیه می‌دهد، آن را حفظ و فرق‌های پیشنهادی را روشن کن:

```text
آنچه از پیش‌نویس شما حفظ شد: [جزئیات و دلیل]
آنچه پیشنهاد اصلاح دارد: [تغییر → دلیل → نیاز به تأیید]
نسخهٔ یکپارچهٔ پیشنهاد: [بلوک کامل]
```

## ۳. درخواست از ایجنت/تیم پورتال پس از بازرسی مستقیم کد

````markdown
# طرح تغییر [موضوع] — هنوز مجوز اجرا نیست
**مرجع:** [repo/branch/SHA/date + فایل‌ها/شماره‌خط‌های تأییدشده]
**مسئله:** [شاهد واقعی در کد، و اگر ممکن بود دادهٔ زنده؛ تفاوت seed و production]
**اثر بر کاربر:** ...
**مقادیر/لینک‌هایی که نباید بی‌اجازه حذف شوند:** ...
**موارد مبهم برای تصمیم مالک:** [گزینه‌ها + مزیت/هزینه]
**گام‌های کوچک و ترتیب:** ...
**پیش‌نیاز/بازگشت:** ...
**تست پذیرش:** [build/test، UI با Chromium + بازبینی تصویر، بررسی دادهٔ live فقط با مجوز]
**نتیجهٔ مورد انتظار و خروجی گزارش:** [مسیر تغییرات، تست واقعی، بازمانده]
````

خط/فایل را **الان** ببین، نه از فهرستِ هندآف کپی کن؛ کد/seed بدون به‌روزرسانی دادهٔ واقعی ممکن است اثر لایو نداشته باشد. اجرای این پرامپت، کار پورتال و نیازمند مجوز مستقل است.

## ۴. گزارش فقط‌خواندنیِ کانال/داده

```text
بازه و timezone: ...            حساب/کانال مجاز: ...
منبعِ واقعی و زمان مشاهده: ...  حد اختیار آزموده‌شده: GET-only / ناموجود
انتشارهای احرازشده: [شناسه/لینک/نتیجه]؛ زمان‌بندی/خطا/نامعلوم: ...
داده: instagram=complete|partial|missing؛ telegram=...؛ blog=...
KPI در برابر هدف: [عدد + نام منبع + بازه] یا missing با دلیل
واقعیت: ...                    برداشت/فرضیه با اندازهٔ نمونه و اطمینان: ...
اقدام پیشنهادی: ...             نیاز به تصمیم/مجوز: ...
کار انجام‌نشده و علت: ...
```

`missing` صفر نیست. Manus فقط تحلیل‌گر دادهٔ تأییدشده است. ارسال پیام/انتشار/هزینه برای کامل‌کردن جدول انجام نمی‌شود.

## ۵. پایان کار، شکست و انتخاب

```text
ساخته/ویرایش شد: [یک یا دو خط و مسیر]
تست شد: [دستور/شاهد/نتیجهٔ واقعی]
تست یا دسترسی نداشتیم: [دلیل، نه حدس]
ماند/تصمیم لازم مالک: [سؤال مشخص یا «هیچ»]
```

```text
مشکل: [نشانهٔ واقعی]
بررسی انجام‌شده: [کدام تلاش‌ها و خطاها، بدون راز]
علت: [اگر معلوم نیست «نامعلوم»]
چه چیزی با همان اختیار ادامه یافت: ...
برای رفع، دقیقاً لازم است: [فایل/نسخه/مسیر یا تصمیم مشخص + منبع رسمی]
```

```text
انتخاب با مالک است:
گزینهٔ الف | فایده ... | هزینه/ریسک ...
گزینهٔ ب | فایده ... | هزینه/ریسک ...
پیشنهاد من: [یک گزینه + یک دلیل]. کدام را انتخاب می‌کنید؟
```

**دستور تغییر فایل توسط خودِ مالک:** برخلاف گزارش عادیِ بالا، **فایل کامل جایگزین** را در یک بلوک کد بده. قواعد قدیمیِ «فایل کاملِ workflow» بر همین اصل تحویل دستی استوار بودند، اما **GitHub Actions مسیر اتصال این استودیو نیست** و در این انتقال قالب workflow/پل تکثیر نشده است.
