# پل بازینو — نرم‌افزار دسکتاپ ویندوز

**نسخه:** ۱.۰ · **تاریخ:** ۲۰۲۶-۰۹-۱۸

نرم‌افزاری که ایجنت بازینو را به کروم شما وصل می‌کند — بدون VPN، بدون کپی‌پیست،
بدون پنجره سیاه.

---

## چه چیزی عوض شد

| قبل | حالا |
|---|---|
| ۶ مرحله راه‌اندازی هر جلسه | یک دکمه |
| ~۷۰ خط پیست در PowerShell | هیچ |
| VPN لازم بود | لازم نیست |
| آدرس `sbx` هر بار عوض می‌شد | آدرسی وجود ندارد |
| پنجره‌ای که نباید داخلش کلیک کنید | پنجره معمولی ویندوز |
| ری‌ست سندباکس = از اول | تأثیری ندارد |

### چرا VPN دیگر لازم نیست

مسیر قدیمی از `sbx-*.arena.site` می‌گذشت که **در شبکه قبرس شمالی بسته است** —
تنها دلیل VPN همین بود.

مسیر جدید از **گیت‌هاب** می‌گذرد. هم سندباکس ایجنت به آن دسترسی دارد (تست شد)،
هم شبکه شما — شاهدش اینکه هر روز بدون VPN کد را push می‌کنید.

---

## نصب — یک بار

### ۱. ورک‌فلو را در گیت‌هاب بسازید

ایجنت اجازه ساخت فایل ورک‌فلو ندارد (محدودیت امنیتی گیت‌هاب)، پس یک بار شما
می‌سازید:

```
گیت‌هاب → ریپو → Add file → Create new file
نام فایل:  .github/workflows/build-bridge.yml
محتوا:     از فایل workflow-build-bridge.yml همین پوشه کپی کنید
Commit
```

### ۲. exe را دانلود کنید

بعد از هر push روی این پوشه، ورک‌فلو خودکار اجرا می‌شود:

```
گیت‌هاب → تب Actions → آخرین اجرا → بخش Artifacts → BazinoBridge
```

فایل zip را باز کنید و `BazinoBridge.exe` را جایی بگذارید که راحت باشد.

⚠️ **SmartScreen** بار اول هشدار می‌دهد چون فایل امضای دیجیتال ندارد:
**More info** → **Run anyway**

### ۳. کلید گیت‌هاب بسازید

نرم‌افزار برای خواندن و نوشتن روی شاخه پیام‌رسان به یک کلید نیاز دارد.

```
github.com → عکس پروفایل → Settings
→ Developer settings  (انتهای منوی سمت چپ)
→ Personal access tokens → Fine-grained tokens
→ Generate new token
```

| فیلد | مقدار |
|---|---|
| Token name | `bazino-bridge` |
| Expiration | ۹۰ روز (یا بیشتر) |
| Repository access | **Only select repositories** → `bazino-advertising-campaign` |
| Permissions → Contents | **Read and write** |

کلید ساخته‌شده را کپی کنید — **فقط یک بار نمایش داده می‌شود**.

### ۴. کلید را در نرم‌افزار وارد کنید

`BazinoBridge.exe` را باز کنید → **Settings** → کلید را پیست کنید → **Save**

کلید با DPAPI ویندوز رمزگذاری می‌شود. فقط حساب ویندوز شما روی همین کامپیوتر
می‌تواند بازش کند.

## استفاده روزانه

```
۱. BazinoBridge.exe را باز کنید
۲. دکمه Connect را بزنید
```

تمام. نرم‌افزار خودش کروم را باز می‌کند و پل را برقرار می‌سازد.

## رفع خودکار خطا

| مشکل | واکنش نرم‌افزار |
|---|---|
| کروم باز نیست | خودش باز می‌کند و ۱۴ ثانیه منتظر می‌ماند |
| کروم وسط کار بسته شد | دوباره باز می‌کند و وصل می‌شود |
| سوکت CDP قطع شد | اتصال مجدد با فاصله فزاینده |
| گیت‌هاب موقتاً در دسترس نیست | تلاش مجدد |
| کلید منقضی شده | پیام واضح + باز کردن Settings |

**فاصله فزاینده:** ۲ → ۴ → ۸ → ۱۶ ثانیه. بعد از ۵ شکست پیاپی متوقف می‌شود و
پیام می‌دهد — به‌جای تلاش بی‌پایان.

## معماری

```
ایجنت (سندباکس لینوکس)          گیت‌هاب           کروم شما (ویندوز)
        │                          │                      │
        │  git push دستور ───────▶ │                      │
        │                    شاخه cdp-bus                 │
        │                          │ ◀─── هر ۲ ثانیه poll │
        │                          │                      │
        │                          │              اجرا با CDP
        │                          │                      │
        │                          │ ◀────── push نتیجه   │
        │  gh api خواندن ◀──────── │                      │
```

**شاخه `cdp-bus`** یک شاخه orphan است — تاریخچه پروژه را آلوده نمی‌کند و هر وقت
بخواهید کامل حذف می‌شود.

```
cdp-bus/
├── cmd/<شماره>.json    ← ایجنت می‌نویسد، نرم‌افزار می‌خواند
├── res/<شماره>.json    ← نرم‌افزار می‌نویسد، ایجنت می‌خواند
└── status.json          ← ضربان
```

### تأخیر

| مسیر | رفت و برگشت |
|---|---|
| پل قدیمی (با VPN روشن) | ۱ تا ۳ ثانیه |
| گیت‌هاب | ۲ تا ۴ ثانیه |

کمی کندتر، ولی VPN نمی‌خواهد و با ری‌ست سندباکس نمی‌شکند.

## امنیت

| نگرانی | کنترل |
|---|---|
| دستورها در ریپو دیده می‌شوند | ریپو **private** است (تأیید شد) |
| کلید گیت‌هاب | فقط `Contents` روی همین یک ریپو · رمزگذاری DPAPI |
| ردپا در تاریخچه گیت | شاخه orphan — قابل حذف کامل |
| توقف فوری | Disconnect · یا بستن نرم‌افزار · یا باطل کردن کلید |

⚠️ نرم‌افزار **هرگز** رمز عبور یا اطلاعات حساس را در شاخه پیام‌رسان نمی‌نویسد.

node tools/bazino-bridge/agent-bus.js targets    # فهرست تب‌ها
node tools/bazino-bridge/agent-bus.js eval "location.href"
